# PromptOS · AI Prompt Command Center

Premium static UI for the supplied **200+ SECRET CODES FOR CHATGPT** codebook.

## Included
- 252 source codewords with number, category, and purpose
- Sidebar navigation and dashboard workspace
- Global and library search
- Category map and command directory
- Favorites stored in localStorage
- Recently used commands
- Prompt Builder with up to 6 stacked codewords
- Copy-to-clipboard and JSON favorites export
- Random command and details modal
- Grid/list views and pagination
- Responsive desktop/tablet/mobile UI
- No framework, build step, backend, or external dependency

## Run
Open `index.html` directly in a browser.

The source PDF says these are custom prompt labels, not official ChatGPT commands.
